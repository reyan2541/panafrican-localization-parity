# Overleaf + GitHub sync

This repository is the source of truth for the PanAfriCon AI 2026 camera-ready paper.

## Open in Overleaf (recommended: live GitHub sync)

1. Go to https://www.overleaf.com
2. **New Project → Import from GitHub**
3. Select repository: `reyan2541/panafrican-localization-parity`
4. After import, click **Menu → Sync → GitHub** and enable sync
5. Set **main.tex** as the Main document
6. Click **Recompile**

Edits in Overleaf can be pushed back to GitHub via Sync; local/git edits can be pulled into Overleaf the same way.

## One-click copy (no live sync)

https://www.overleaf.com/docs?snip_uri=https://github.com/reyan2541/panafrican-localization-parity/archive/refs/heads/main.zip

## Compile

`main.tex` contains an inline bibliography, so pdfLaTeX alone is enough (BibTeX not required).
